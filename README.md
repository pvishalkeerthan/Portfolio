# Vishal Keerthan Parankusham | Product Engineer

A professional, high-density broadsheet-style portfolio built with Next.js and Tailwind CSS. This portfolio features a unique "ink-on-paper" editorial aesthetic, optimized for a single-viewport experience.

## ✨ Features

- **Editorial Design**: Custom broadsheet newspaper aesthetic with fluid typography and hairline rules.
- **Single Viewport**: Optimized to provide a high density of information without requiring scrolling on desktop.
- **Responsive Layout**: Adaptive column strategy and fluid sizing for a consistent experience across all devices.
- **Dynamic News Wire**: Real-time "On The Wire" slider for current focus and recent launches.
- **Hall of Fame**: Highlighted achievements and hackathon wins in a clean, professional grid.

## 🛠️ Technology Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Typography**: Playfair Display, Oswald, Courier Prime
- **Deployment**: Vercel

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
